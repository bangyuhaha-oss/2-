## 约90秒代码入口

| 入口 | 建议讲解 |
| --- | --- |
| `app.py:create_app`、`prepare_request` | Flask工厂建立配置，每请求连接SQLite、读取服务端会话、所有POST验证CSRF。不是靠隐藏按钮实现权限。 |
| `app.py:role_required`、`employees`、`my_schedule` | 角色装饰器检查HR/主管/员工；主管查询加本队条件；个人排班只用绑定员工身份。 |
| `models.py:Employee.validate/create/update/delete` | 七字段校验、参数化SQL和版本检查；DELETE通过外键撤销关联访问与记录。 |
| `models.py:ScheduleWeek.save` | 写事务锁内核查当前团队和周规则，再统一替换；TC34真实中途ABORT证明回滚。 |
| `app.py:check_in`、`models.py:CheckIn.record` | 检查实际来源、签名操作令牌及本人身份；数据库唯一约束处理重试。 |
| `database.py:initialize/seed_demo` | 表和外键；500条虚构初始化仅运行一次；示例班表是固定演示数据。 |
| `templates/employee_form.html`、`team_schedule.html` | Jinja转义输出、HTML form GET/POST和复选框，CSP禁止页面脚本。 |
| `workspace.py:directory_filters/csv_download/safe_csv_cell` | 同一白名单条件供目录、全部匹配CSV及返回上下文；标准库CSV+BOM和公式文本保护；不接受任意next跳转。 |
| `workspace.py:team_week_summary/personal_week/checkin_filters` | 计划人数/班次/小时分开，今日不随历史选周改变，下次仅精确90天，签到历史同一日期条件用于列表/导出/打印。 |
| `app.py:team_schedule` | GET载入上周仅预填页面、保留目标版本，人工审阅确认后才提交原整周事务；不是自动排班。 |
| `scrum/board.py:update/evidence_files` | Done文件路径边界、当前时间日志、拟定负责人和自报操作者区分；不是成员贡献证明。 |

`evidence/website_code_index.json` 记录最终源码中的函数/类起始行，可在编辑器直接跳转。代码行号随后续修改变化时应重新生成。
